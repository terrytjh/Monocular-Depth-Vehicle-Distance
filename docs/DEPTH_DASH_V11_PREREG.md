## 1. 方法

兩條鏈,共用顯卡的部分(偵測器、DA3、MoGe-2、每幀深度圖):

### 1.1 R 鏈:第十版,照 `docs/DEPTH_DASH_V10_PREREG.md`

相機常數照第十版登錄(從第 8 包 v9d 複製,不重學):相機 k 白天 0.89480、夜間 0.78711,相機 A 1071.77
(`docs/DEPTH_DASH_V11_CHUNK9/constants_v10_registered/`)。輸出 `v10/<tag>_cars_v10.json`。

### 1.2 N 鏈:第十一版

N 鏈以 R 鏈的輸出資料夾為底(影格、偵測框、虛線尺、深度與 MoGe-2 快取、每幀深度圖),用 `tools/v11/chain.py` 在 repository
的一份工作複本上重跑第九、十版的步驟與第十一版的後處理。相對第十版的改動:

1. **分級輸出,不整段拒發**:t1 自己的尺;t1n 自己的尺、但該幀沒有車道線對(每幀深度圖的幀);t2k 同相機常數;t2f 拒發段用
   相機常數補位(每組都補,另外標示、分開報);t4d DA3 名目焦距(標「未校正」)。
2. **60 m 外照給距離**,標 far60,附 95% 範圍。
3. **自車速補位**:主要組 MH(MS / MC)加 C2(±6 秒);夜間 K2-ego + E1;一般道路 E1;新補自車速的秒也算前車絕對速度。
4. **K4**:被擋 ≥ 30% 或碰邊的框不給距離(門檻 0.30 / 5 px / 3 px,只在開發批重選)。
5. **相對速度簡單版**:讀點從框底往上 25%(原 6%),有 MoGe-2 就用 MoGe-2;距離不變。
6. **每幀深度圖(T2)**:每一組都補,標 t1n。
7. **引擎蓋輪廓規則**:引擎蓋線以下不給框、碰到引擎蓋的框不給距離。
8. **不對稱 95% 範圍**:上下限分開學,放寬到每個留一批的批都覆蓋 ≥ 95%;用加入第 10–12 項後的開發輸出重學
   (`tools/v11/v11f/v11f_params.json`,sha256 見第 4 節清單)。
9. **相機常數**:從開發批(含第 8 包)只用預測重學:相機 k 白天 0.90031、夜間 0.78868,相機 A 1073.24
   (`docs/DEPTH_DASH_V11_CHUNK9/constants_v11/`);日夜灰階與 k_camera_also 用 R 鏈的。
10. **分車道路面校正**(`tools/v11/gl_patch.py`):路面校正除了本車道,也擬合左車道 [x_l − W, x_l] 與右車道 [x_r, x_r + W]
    的路面列(W = 該列本車道寬),同一套接受條件,加一條 |a_side / a_own − 1| ≤ 0.15;第 −1 / +1 道的車用該側的校正。
11. **自車速的尺只用沒被截短的週期**(`tools/v11/eg_patch.py`):標線幾何速度用的尺(每條線的局部尺與全段尺)只用
    z_near + (1.25 + 工作比) × 週期 ≤ 該幀亮度剖面遠端的週期。距離用的尺、週期本身與其他步驟不變。
12. **夜間偵測前調亮**(`tools/v11/a2_detect.py`):R 鏈 `grey.json` < 50 的段,偵測器的輸入先做 gamma 0.5,門檻 0.25;
    追蹤與之後的步驟讀原始影格。

不用的(開發時評過、沒過事前標準,或原則上不用):
- 用相機常數在 14.63 / 7.32 m 兩個法定週期之間選:觸發段量到的週期約 7.59 m,不是 7.32 m,距離與自車速都變差。
- 夜間只降門檻(不調亮):三批中兩批 30 m 內中位誤差多 0.35–0.37 個百分點(上限 0.3)。
- 反光標記配對:夜間鎖在半週期的比例 79.7 → 38.0% 降了,但夜間 C6 中位誤差多 1.79 個百分點、C7a 找到率下降。
- 任何看開發答案擬合的乘數(自車速 ÷ 1.0178、右車道放大、夜間 k 倍數、遠距離修正係數)。
