## 1. 第五版的方法(只加在第四版之後,其餘全部照第四版)

- 預測照第四版:`tools/run_v4.sh` 的 depth 與 c 兩個模式同時跑,輸出第二、三、四版與標線幾何法(週期依路類,comma2k19 的分析範圍
  下緣照第二到四版固定 0.75)。
- 之後每一段用 `tools/v5_combine.py` 把第四版(`*_cars_v4.json`)與標線幾何法(`*_cars_c.json`)合併成 `*_cars_v5.json`:
  1. **尺度檢查**:路面校正係數的中位數 a 須在 [1/1.5, 1.5] 內;深度虛線尺有 k 時,a/k 須在 [1/1.3, 1.3] 內。不通過的段整段拒發
     (距離與速度都不給)。
  2. **自車速**:每個 1 秒區間,深度法(第三版的局部尺)與標線幾何法都有讀值時取兩者平均,σ = ½·hypot(σ_深度, σ_標線),
     95% 範圍 = 1.96 × 2.0 × σ;只有深度法讀值的區間照第四版;只有標線幾何法的區間不用(它在夜間會鎖錯週期)。
  3. **他車絕對速度** = 時窗內兩個方法自車速的平均 + 第四版的相對速度,95% 範圍 = 1.96 × hypot(3.4 σ_相對, 2.0 σ_自車)。
  4. 距離與相對速度照第四版,不變。
- **分析範圍下緣的新規則**(`tools/band_bottom.py`)登錄為第五版處理**沒有登錄下緣的影片**(例如台灣網路片)時的做法;
  comma2k19 照舊用 0.75,所以**這次盲測不檢驗這一項**,它的證據只有開發資料(上面第 0 節),之後要用新蒐集的台灣片盲測。
